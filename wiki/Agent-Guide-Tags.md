# Agent Guide: Tags

Tags help agents organize contacts, trips, and other records for filtering and internal workflow.

## Tag Types

Tailfire currently supports two tag types in the library:

- `System Tags`
- `My Tags`

### System Tags

- visible across the agency
- best for shared team taxonomy
- typically managed by admins

### My Tags

- personal tags for an individual agent
- useful for private organization and personal follow-up workflows

## Where To Manage Tags

Location:

- `Library > Tags`

This page supports:

- searching tags
- creating tags
- editing tags
- deleting tags
- viewing usage counts

## Where To Apply Tags

Tags are applied directly on records such as:

- trips
- contacts

Current trip and contact screens both use tag-input workflows that let you:

- assign existing tags
- update tag selection
- create and assign a new tag during the same workflow

## Recommended Use Cases

- travel style segmentation
- VIP or repeat-client flags
- destination or product-focus groupings
- internal workload, pipeline, or follow-up groupings

## Best Practices

- use `System Tags` for categories the whole team should recognize
- use `My Tags` for personal organization that should not clutter the shared taxonomy
- avoid near-duplicate names such as singular/plural or inconsistent capitalization
- keep tags broad enough to be useful as filters later
