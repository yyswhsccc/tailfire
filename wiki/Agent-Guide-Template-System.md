# Agent Guide: Template System

Tailfire currently has more than one kind of template. This page explains the differences and when to use each one.

## The Three Template Families

### 1. Itinerary Templates

Location:

- `Library > Itinerary Templates`

Use these when you want to reuse an itinerary structure with days and activities.

You can:

- create a template directly in the library
- save an existing itinerary as a template from a trip
- apply a template to a trip to create a new itinerary

What they are good for:

- repeatable destination frameworks
- standard leisure trip outlines
- reusable group or FIT itinerary structures

### 2. Package Templates

Location:

- `Library > Package Templates`

Use these when you want to reuse a package or multi-day cluster of activities inside an existing itinerary.

You can:

- create package templates in the library
- save an existing package as a template from a trip
- apply a template into an itinerary anchored to a specific day

What they are good for:

- add-on experiences
- cruise pre/post packages
- bundled day clusters that repeat across trips

### 3. Document Templates

Location:

- `Library > Templates`

Use these for rendered documents and formatted outputs, not for itinerary structure.

Current categories include:

- `Trip Order`
- `Payment`
- `Email`
- `Proposal`

Key behaviors:

- some templates are system templates and read-only
- system templates can be forked into an agency copy
- templates can be edited, published, and archived
- preview is available before sending or publishing

## Related But Separate: Email Templates

Automation email templates are managed separately under:

- `Library > Notifications`

These are for notification and automation messaging, with preview and test-email flows.

## How To Choose The Right Template Type

- Use `Itinerary Templates` when you want to create a whole itinerary quickly.
- Use `Package Templates` when you want to insert a reusable block into an existing itinerary.
- Use `Document Templates` when you want to control rendered outputs such as trip orders, proposals, or payment documents.
- Use `Email Templates` when you are working with automated or notification-style email content.

## Saving Existing Trip Content As A Template

When you are inside a trip:

1. open the itinerary or package you want to reuse
2. use `Save as Template`
3. give the template a clear name and optional description
4. store it in the library for future trips

When saved from a trip, templates preserve the structure and content but dates are recalculated when they are applied to a new trip.

## Best Practices

- use names that describe audience, destination, or use case
- keep reusable templates generic enough to adapt
- prefer editing the template in the library instead of cloning the same template repeatedly without cleanup
- publish only the document templates that are ready for live use
