# Agent Guide: Libraries

This page explains what the Library area is for and how agents should use it.

## What The Library Is

The Library is the shared resource area inside the admin app. It holds reusable trip content, reference catalogs, and agency-managed configuration data.

The Library route redirects into the first section, but the left sidebar is the real navigation model.

## Main Library Sections

### Travel Activities

- `Itinerary Templates`
- `Package Templates`
- `Cruises`
- `Tours`

Use these when you want reusable trip structures or reference travel content.

### Trip Components

- `Suppliers`
- `Loyalty Programs`
- `Payment Schedules`

Use these to support booking, traveler profile, and financial workflows.

### Organization

- `Tags`

Use tags to organize trips, contacts, and other records for filtering and segmentation.

### Communications

- `Templates`

Use this area for document-style templates such as trip orders, payment documents, proposal documents, and email-category document templates.

## How Agents Usually Use The Library

1. Start in the Library when you need something reusable or shared.
2. Use itinerary or package templates to speed up trip building.
3. Use cruises and tours as research/reference libraries when building client trips.
4. Use tags and loyalty programs to keep contact and trip data organized.
5. Use template areas to preview, customize, or publish reusable content.

## What Not To Confuse

- `Itinerary Templates` and `Package Templates` are trip-building tools.
- `Templates` under Communications are document templates, not itinerary templates.
- `Email Templates` for notifications live under `Library > Notifications`, separate from the document-template editor and separate from your personal email inbox.

## Best Practices

- Store reusable structures in the library instead of rebuilding the same trip framework repeatedly.
- Keep shared library content clean and consistently named so other agents can find it.
- If a template or catalog item is agency-wide, use a naming convention the whole team will recognize.
