# Agent Guide: Loyalty Programs

Loyalty Programs in Tailfire work at two levels: the agency catalog and the individual contact record.

## Level 1: Agency Catalog

Location:

- `Library > Loyalty Programs`

This is where the team maintains the master list of supported programs.

Current catalog fields include:

- provider
- program name
- type such as cruise, airline, hotel, or other
- active or inactive status

Use the catalog to keep naming and program types consistent across the agency.

## Level 2: Contact Membership Records

Location:

- open a contact
- go to the loyalty-program area on that contact record

This is where you store the traveler’s actual membership details, including:

- provider name
- program name
- membership number
- tier level
- notes

## Typical Workflow

1. Confirm the program exists in the loyalty-program catalog.
2. Open the contact record.
3. Add the traveler’s loyalty membership.
4. Record tier level or notes if relevant.
5. Reuse that membership detail later when building bookings or passenger details.

## Why This Matters

Keeping loyalty data on the contact helps the team:

- retain traveler preferences and benefits
- reuse loyalty information across future trips
- surface existing memberships in workflows such as cruise passenger handling

## Best Practices

- keep the catalog clean and use one naming convention
- store the actual membership number on the contact, not in the catalog
- record notes only when they will help future servicing
- deactivate obsolete programs in the catalog instead of letting duplicates accumulate
