# Agent Guide: Create A Trip

This article explains how agents create a new trip record and what to set up first.

## What A Trip Record Is

A trip is the main working file for a client journey. It is where you organize travelers, itinerary options, activities, pricing, bookings, payments, service fees, media, and proposal sharing.

Creating the trip comes first. The itinerary and supplier-booking steps happen afterward.

## Before You Start

- Have a clear trip name ready.
- Decide whether you know the travel dates yet.
- If the trip belongs with a larger series or departure group, know which trip group to use.
- If your team relies on tags, decide which tags should be applied at creation time.

## How To Create The Trip

1. Open the trip creation dialog from the Trips area.
2. Enter the trip name. This is required.
3. Choose the trip type if it helps your agency reporting or filtering.
4. Enter the trip dates, or use `Add Dates Later` if dates are still unknown.
5. Set the trip timezone when you know it.
6. Assign a trip group if this record belongs to a larger grouped workflow.
7. Add tags if you want the trip organized from the start.
8. Optionally add a cover photo from the image picker.
9. Save the trip. Tailfire will usually open the new trip workspace immediately after creation.

## What To Do Next

After the trip is created, the normal next steps are:

1. Add travelers.
2. Create or import an itinerary.
3. Build the itinerary with the right activities or packages.
4. Apply tags, media, and any trip-level organization details you skipped at creation time.

## Good Setup Habits

- Use a trip name your whole team can recognize quickly.
- Only use `Add Dates Later` when dates are truly unknown. Date-driven itinerary behavior is easier once dates are set.
- Add tags early if they affect reporting, queues, or saved filters.
- Use trip groups for related files instead of putting grouping logic into the trip name.
- If dates are added later, Tailfire may generate or extend itinerary days depending on the existing itinerary setup.
