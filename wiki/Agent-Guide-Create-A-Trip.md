# Agent Guide: Create A Trip

This article explains how agents create a new trip record and set its starting stage correctly.

## What A Trip Record Is

A trip is the main working file for a client journey. It holds travelers, itinerary options, bookings, payments, service fees, documents, notes, and proposal-sharing work.

## Before You Start

- choose a clear trip name
- decide whether dates are known yet
- know whether the file should begin in **Inbound** or **Planning**
- identify any trip group or tags you want applied immediately

## How To Create The Trip

1. Open the trip creation dialog from the Trips area.
2. Enter the trip name.
3. Choose the starting **Status**: **Inbound** or **Planning**.
4. Set trip type, dates, timezone, group, and tags as needed.
5. Save the trip and open the trip workspace.

## Stage Guidance

- Use **Inbound** when the trip is still an intake or qualification file.
- Use **Planning** once the trip is an active planning workspace.
- Do not expect **Active**, **Travelling**, or **Travelled** to be manual starting states; those are system-driven later in the lifecycle.

## What To Do Next

1. Add travelers.
2. Open the **Itinerary** tab.
3. Create or import the first itinerary option.
4. Continue with proposal and booking work from there.
