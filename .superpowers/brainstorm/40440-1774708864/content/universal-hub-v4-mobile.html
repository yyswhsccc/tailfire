The Travel Magazine Feed

No sections. No tabs. No rigid grids. Content types blend together in a flowing feed — a cruise card sits next to a hotel card sits next to a photo mosaic. Each card is tagged with its type (🚢 Cruise, ✈️ Flight, 🏨 Hotel, 🎯 Activity, 🗺️ Tour) so the consumer always knows what they're looking at.

Card types mix naturally:
• Full-width cruise card (image + details)
• Side-by-side activity + hotel pair
• Horizontal tour card (image left, text right)
• Photo mosaic break
• Flight comparison card
• More products blended in...

Mobile-first principles:
• Full-bleed hero with text ON the image
• Cards have generous padding + rounded corners
• Touch targets are large
• Horizontal scroll for "Explore Nearby"
• Floating AI concierge button

Speed:
• Hero + description = instant (cached)
• Each card streams in via Suspense
• Photos lazy-load on scroll
• Feels like scrolling Instagram, not waiting for a page
