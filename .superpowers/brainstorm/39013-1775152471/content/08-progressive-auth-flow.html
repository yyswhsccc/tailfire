What happens on identity capture

  1. CRM lookup by email + agencyId
  2. Existing contact? Link trip to them
  3. New? Create contact in Tailfire CRM
  4. Link all session drafts to this contact
  5. Generate share token for board URL
  6. Board name stored as trip request title

30-day expiry

Unnamed/unidentified drafts expire after 30 days. Named boards with email persist indefinitely. The AI can remind users to name their board when it has 3+ items.
